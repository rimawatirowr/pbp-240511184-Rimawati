# Refleksi

Platform yang paling menarik bagi saya adalah Web. Saya sudah terbiasa membuat web, jadi HTML, CSS, dan JavaScript terasa tidak asing. Selain itu, web bisa dibuka dari perangkat apa saja hanya lewat browser, sehingga hasil karya saya mudah dibagikan dan dicoba orang lain.

Tantangan terbesar saat setup environment adalah ketika perintah node dan npm tidak dikenali di terminal. Setelah Node.js terinstal, npm masih diblokir oleh kebijakan keamanan PowerShell sehingga muncul pesan bahwa script tidak boleh dijalankan. Saya juga sempat salah folder saat menjalankan git clone, sehingga repository tersimpan di folder proyek lain dan terminal tidak mengenalinya sebagai repository.

Rencana saya untuk mengatasi tantangan seperti ini adalah membaca pesan error dengan teliti sebelum mencoba solusi apa pun. Saya akan memeriksa dokumentasi resmi atau mencari pesan error tersebut, lalu mencoba solusinya langkah demi langkah. Saya juga akan selalu memeriksa folder aktif di terminal sebelum menjalankan perintah, serta menutup dan membuka ulang VS Code setelah menginstal program baru agar perubahannya terbaca.
