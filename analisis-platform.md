# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript (TypeScript, PHP, Python di sisi server) | C#, C++, Java, Python; bisa juga Electron (JavaScript) | Kotlin/Java (Android), Swift (iOS), Dart (Flutter) |
| Arsitektur | Client-server: browser sebagai client, server menyimpan logika dan data | Berjalan langsung di sistem operasi, sering berdiri sendiri (standalone) | Berjalan di OS mobile, terhubung ke API/backend, dibatasi sandbox OS |
| Cara distribusi | Diakses lewat URL di browser, tanpa instalasi | Installer (.exe, .msi, .dmg) dari website atau toko aplikasi | Toko aplikasi (Google Play, App Store) |
| Keunggulan | Lintas perangkat, mudah diperbarui, tanpa instalasi | Performa tinggi, akses penuh ke perangkat keras, bisa offline | Akses sensor (kamera, GPS), notifikasi, nyaman dibawa |
| Keterbatasan | Tergantung internet dan browser, akses perangkat keras terbatas | Harus diinstal, berbeda tiap OS, update manual | Perlu persetujuan toko aplikasi, layar kecil, fragmentasi perangkat |
| Contoh aplikasi | Google Docs, Tokopedia (web), GitHub | Visual Studio Code, Microsoft Word, Adobe Photoshop | WhatsApp, Gojek, Instagram |
